## Question

`Tree<T,IndexT>` (`cxx/traaxx/include/traaxx/traaxx.hpp`) сейчас — агрегат с тремя публичными полями `parent`/`sibling`/`data`. Новый набор операций добавляет пять мутаций (§11.2–§11.7), каждая из которых поддерживает свои, довольно тонкие правила консистентности (зашивание цепочки братьев при удалении, gate на цикл при перемещении, полная пересборка при удалении поддерева). С публичными полями ничто не мешает вызывающему коду записать в `parent`/`sibling`/`data` напрямую, в обход этих правил.

Нужно решить: делать ли поля приватными с аксессорами, и если да — как тогда получают доступ (а) операции, которым нужно только читать структуру (propagation, DFS/BFS-порядок, LCA, валидация), и (б) операции, которым нужно писать (пять мутаций)?

## Answer

`parent`/`sibling`/`data` становятся **приватными** полями `Tree<T,IndexT>`, с `const`-аксессорами для чтения (`const std::vector<IndexT>& parent() const`, аналогично `sibling()`/`data()`, плюс `size()`/`nodes_count()`).

- **Пять мутаций** (`append`/`deleteLeaf`/`deleteSubtree`/`splice`/`move`, §11.2–§11.7) — становятся **методами `Tree<T,IndexT>`**: только они получают привилегированный доступ на запись к приватным полям, и только через них дерево может измениться. Каждый метод мутирует `*this` на месте (в том числе те, что по теории требуют полной пересборки векторов, §11.5 — пересборка тоже пишется как замена содержимого приватных полей внутри метода, не как возврат нового `Tree`).
- **Операции только для чтения** (propagation-маска, производные векторы, DFS/BFS-переупорядочивание без переноса `data`, LCA, `validate_invariants`) — остаются **свободными функциями**, принимающими `const Tree<T,IndexT>&` (или сырые векторы, полученные через аксессоры) — они не входят в интерфейс `Tree`, потому что не отвечают за его консистентность, только читают.

Это решение фиксирует общий принцип API-поверхности для всего оставшегося набора: единственный узаконенный способ изменить дерево — вызвать один из пяти методов-мутаций; всё остальное в этой карте — функции, которые дерево не трогают.
