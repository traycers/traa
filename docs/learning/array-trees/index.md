## О чём этот материал

Справочник по тому, как устроены **деревья на базе массивов** в подходе Aaron W. Hsu (co-dfns, APL): дерево — не структура с указателями, а пара плоских векторов `parent` + `sibling` (плюс производные от них величины), над которой все привычные операции с деревом (обход, поиск предка, изменение структуры) выражаются как операции над массивами — без рекурсии, без указателей, дружественно к SIMD и параллельным архитектурам.

Это теоретическая основа, на которую опирается собственное представление дерева проекта **traa** (см. `.scratch/array-trees/` в корне репозитория — там же зафиксировано собственное представление: обобщённый (generic/шаблонный) payload, полная поддержка всех операций из этого конспекта).

## Терминология (сквозная по всем файлам)

- **`parent`** — вектор: `parent[i]` — id родителя узла `i`; корень — `parent[i] == i` (самоссылка вместо null).
- **`sibling`** — вектор: `sibling[i]` — id **левого** соседа узла `i` (предыдущего ребёнка того же родителя); первый ребёнок — `sibling[i] == i`.
- **Инвариант порядка** — `parent[i] <= i`, `sibling[i] <= i`: узел физически создан не раньше своего родителя/левого соседа. Даёт бесплатную ацикличность и однопроходные версии propagation ([`04-mask-propagation.md`](04-mask-propagation.md) §5.3).
- **Propagation** — повторяемое применение операции вдоль векторной ссылки (`parent`/`sibling`/таблица прыжков) до неподвижной точки — замена рекурсии в этом подходе ([`05-propagation-pattern.md`](05-propagation-pattern.md)).
- **DFS/BFS-порядок** — переупорядочивания узлов, каждое даёт что-то бесплатно (поддерево — диапазон у DFS, уровень — диапазон у BFS), но ценой инварианта порядка после самой перестановки.
- **LCA** — ближайший общий предок (least common ancestor).
